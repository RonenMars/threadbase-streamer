## Summary for D2/D4/D6/D15
- **Single-writer model holds in 0.150.1** (X0.3, X01, X07): sequential ownership works, concurrent never; lock is liveness-checked.
- **`requestUserInput` is not a production contract in 0.150.1** (X02/STOP-T7): default-off, under development, not advertised by any stable negotiation surface, not reachable through a documented mode switch.
- **Terminal → app-server → terminal on the same rollout is impossible while the terminal lives** (X01): refused-terminal-intact only.
- **Pending approvals reconcile on reconnect to a live provider** (X04a/b/d); after provider death they are marked `interrupted` and dropped (X04c).
- **Agent-spawned interactive commands cannot be fed stdin/resized from the app-server client** (X06); interrupt works.
