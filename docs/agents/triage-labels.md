# Triage labels

**The vocabulary is canonical in [`threadbase/docs/triage-labels.md`](https://github.com/RonenMars/threadbase/blob/main/docs/triage-labels.md).**
Read that file for the label meanings, their colours, and the rule that they are additive to priority, type and area rather than a substitute for any of them.

This file records only what is true of *this* repo.

All five labels exist on `RonenMars/threadbase-streamer`.
`wontfix` predates the scheme; `needs-triage`, `needs-info`, `ready-for-agent` and `ready-for-human` were created on 2026-08-20, at the same colours `threadbase-mobile` uses, so the two trackers are interchangeable to a reader moving between them.

When a skill mentions a triage role — "apply the AFK-ready triage label" — use the label string from the canonical table.
